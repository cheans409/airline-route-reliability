# Planned Tableau dashboard

- Overview: reported flights, cancellations, diversions, eligible late arrivals, and missing outcomes.
- Route prioritization: volume versus disruption rate, with a minimum-volume filter.
- Seasonality: monthly route and carrier trends.
- Drill-down: directional route, carrier, month, counts, and denominators.

Filters: month, carrier, origin, destination, and minimum flight count. Every chart must identify its eligible population. Dashboard implementation has not started.
